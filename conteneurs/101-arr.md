## Fonctionnement

```
Seerr ─► Sonarr / Radarr ─► Prowlarr (indexeurs) ─┐
                    │                             ├─ via gluetun ─► Internet (ProtonVPN)
                    └──► qBittorrent ─────────────┘
qBittorrent écrit dans /data/downloads ; Sonarr/Radarr rangent dans /data/media (liens physiques)
Bazarr ajoute les sous-titres ; Plex (CT 100) lit /data/media
```

- Prévenir Plex après import : connexion *Settings → Connect → Plex Media Server* (hôte `192.168.1.100`, port `32400`, « Update Library ») à créer dans Radarr et Sonarr. Au 07/10/2026 : **pas encore faite** (Plex rattrape avec sa propre surveillance des dossiers, voir [100-plex.md](100-plex.md)).
- `FIREWALL_OUTBOUND_SUBNETS=192.168.1.0/24` : les *arr du LAN peuvent joindre Prowlarr/qBittorrent.
- Quand ProtonVPN attribue un port, gluetun lance `/gluetun/qbt-port.sh` qui le règle dans qBittorrent
  (copie : [config/ct101-arr/qbt-port.sh](../config/ct101-arr/qbt-port.sh)).
- Sauvegardes du compose : `docker-compose.yml.bak`, `docker-compose.yml.bak-cloudflared`.

## Supprimer un film

Sur l'hôte (en SSH, aussi depuis le téléphone via Tailscale `100.73.1.43`) :

```sh
supprimer-film "titre"          # demande confirmation
supprimer-film --test "titre"   # montre ce qui serait supprimé
```

Retire le film de Radarr avec ses fichiers (`/data/media`), puis supprime le torrent et son fichier dans qBittorrent (`/data/downloads`).
Script : `/usr/local/bin/supprimer-film` (source : [scripts/supprimer-film](../scripts/supprimer-film)).
